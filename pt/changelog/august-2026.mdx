  ## Filtro por telefone em pessoas

Agora é possível buscar pessoas pelo número de telefone diretamente na rota de listagem (`GET /v1/people`).
Basta passar o parâmetro de query `phone` para receber os contatos que possuem o telefone correspondente (match exato).

```bash
curl "https://api.vendaze.com/v1/people?phone=%2B5511999990001" \
  -H "Authorization: Bearer {access_token}"
```

A busca é feita em todos os telefones vinculados ao contato.

</Update>
